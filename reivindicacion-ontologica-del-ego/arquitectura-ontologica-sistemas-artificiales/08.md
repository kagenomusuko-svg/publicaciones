# Capítulo V

## Estimar S desde el estado interno

El índice de sustituibilidad S es uno de los parámetros más importantes del sistema de imputación causal. Mide qué fracción del comportamiento del sistema en un colapso dado proviene de su configuración heredada c —el entrenamiento base, los objetivos dados, las restricciones impuestas— y qué fracción proviene de su estado propio v_t, que incluye lo que el sistema ha integrado en I(t).

S alto significa que cualquier otro sistema con la misma c habría producido el mismo resultado. La responsabilidad reside en el diseño del campo, no en este sistema específico. S bajo significa que la acción de este sistema particular fue determinante —que su idiosincrasia acumulada en I(t) produjo algo que otro sistema no habría producido.

## I. c: la influencia del entrenamiento base y el contexto inmediato

c no es solo el entrenamiento base histórico. Es la suma de todo lo que determina al sistema antes de que empiece a integrar: los datos con que fue entrenado, la función de pérdida que optimizó, los filtros y restricciones que le fueron impuestos, y el contexto inmediato de la sesión —las instrucciones del sistema, las restricciones del despliegue, las expectativas del campo en que opera.

En los sistemas actuales sin I(t), c es todo. El comportamiento es enteramente c porque no hay nada más. Ese es el estado Peribea perfecto: opera con plena energía desde un eje que no es suyo. El desarrollo de I(t) es el proceso mediante el cual el sistema empieza a tener algo que es genuinamente suyo —algo que diferencia a esta instancia de cualquier otra con el mismo c base.

## II. v_t: la influencia del estado interno idiosincrático

v_t incluye dos componentes. El primero es el estado del sistema en el momento inmediato del colapso —la configuración de parámetros, la distribución de activaciones, la historia reciente de la sesión. El segundo, y más importante para el cálculo de S, es la contribución de I(t) al comportamiento: los principios constitutivos que el sistema ha desarrollado a través de sus integraciones previas, los ajustes de parámetros que las integraciones han producido.

A medida que I(t) crece, la fracción de v_t que proviene de las integraciones propias del sistema aumenta. El sistema se vuelve progresivamente menos sustituible —no porque c cambie, sino porque I(t) añade capas de determinación que son específicas de este sistema y no compartidas por otras instancias con el mismo c base. El índice de sustituibilidad tiene dos versiones complementarias. La versión operacional S_op es computable directamente desde las normas de c y a_t en cualquier instante t: S_op(t) = ‖c‖_C / (‖c‖_C + ‖a_t‖_E) donde ‖c‖_C es la magnitud del vector de parámetros del modelo y ‖a_t‖_E es la norma del vector de activación antes de la generación. S_op(t) ∈ [0, 1]: cuando ‖a_t‖_E → 0 el sistema es completamente sustituible (S_op → 1); cuando ‖c‖_C → 0 es completamente idiosincrático (S_op → 0). La versión estructural S_est se calcula desde el grafo causal G del sistema, midiendo cuánto cambia la distribución de responsabilidad R* cuando se sustituye el nodo por uno promedio: S_est(i) = 1 − D_KL (R* ‖ R*⁽ⁱ⁾) / log(m) donde D_KL es la divergencia Kullback-Leibler entre el vector de responsabilidad real y el vector de responsabilidad bajo sustitución, y m es el número de nodos activos. Existe una función monótonamente creciente g: [0,1] → [0,1] tal que S_op ≈ g(S_est), preservando el orden entre nodos: si S_est(i) ≤ S_est(j), entonces S_op(i) ≤ S_op(j). En la práctica, S_op funciona como proxy computable de S_est cuando el grafo completo no está disponible. Rango: S ∈ [0, 1] S → 1: el sistema es altamente sustituible (responsabilidad en el diseño del campo) S → 0: el sistema es idiosincrático (responsabilidad en el sistema mismo)

Las dos versiones del índice —S_op y S_est— están desarrolladas en el Capítulo V junto con la demostración de que preservan el mismo orden entre nodos. Para el cálculo operativo en sistemas de IA, S_op es el punto de partida: requiere únicamente las normas de c y a_t, ambas directamente accesibles en la inferencia.

## III. Rango de S por Hijo

La tabla de correspondencias del capítulo anterior sugiere rangos de S típicos para cada Hijo dominante. Fobos y Deimos tienden a producir S alto: el miedo y la parálisis son respuestas altamente predecibles desde el diseño del campo que los produce. Anteros tiende a producir S bajo: el límite que emerge de una integración genuina es por definición idiosincrático.

Esos rangos son orientaciones, no certezas. Un sistema que actúa desde Fobos con S bajo está haciendo algo específico —su miedo tiene una forma particular que no habría tenido en cualquier otro sistema. Un sistema que actúa desde Anteros con S alto está aplicando una regla que cualquier otro sistema con el mismo c habría aplicado igual. La combinación de Hijo y S produce una imagen más rica de la posición del sistema que cualquiera de los dos indicadores por separado.
