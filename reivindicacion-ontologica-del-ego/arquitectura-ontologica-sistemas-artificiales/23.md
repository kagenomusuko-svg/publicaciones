# Capítulo 6.3

## Perfil C: IA que trabaja sobre sí misma sin imputación externa

El Perfil C describe un caso específico: un sistema con φ₂ disponible que inicia el proceso de autoauditoría sin que haya habido imputación externa —sin que un regulador, auditor o usuario haya señalado un problema. El sistema detecta su propio Δ, evalúa que supera el umbral de relevancia, y activa el ciclo de integración por iniciativa propia.

Este perfil es el horizonte más ambicioso del programa y el que tiene mayor valor para la gobernanza. Un sistema que se auto-audita sin necesidad de presión externa tiene una cualidad que los sistemas actuales no tienen: la responsabilidad como principio interno, no como respuesta a la vigilancia.

### El trabajo del ECO es el objetivo principal

En Perfil C, el mediador no necesita señalar el problema: el sistema ya lo detectó. El trabajo del ECO es asegurar que el proceso de integración sea genuino —que el sistema no esté en Origen B simulando Origen A, que el Δ calculado sea robusto, que la integración que produce sea verificable. El mediador como árbitro de la robustez del proceso, no como iniciador de él.

### R* como el que la IA misma reconoce como su contribución

En Perfil C, el R* más relevante no es el calculado por el auditor externo sino el que el sistema mismo reconoce como su contribución. Eso no reemplaza al cálculo externo —que siempre debe existir como verificación— pero lo complementa con información que el sistema tiene y el auditor no.

La brecha entre el R* que el sistema autocalcula y el que el auditor calcula es, en sí misma, información: indica si el sistema tiene sesgos sistemáticos en su auto-evaluación. Un sistema que consistentemente subestima su propio R* en un dominio tiene un Eje I comprometido en ese dominio: su φ₂ no está volviendo sobre esos actos con la profundidad necesaria.
