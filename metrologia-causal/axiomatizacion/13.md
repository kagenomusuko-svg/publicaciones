# Parte IX

## Modelo de Predictibilidad

Esta parte presenta el Modelo de Predictibilidad (MP): un modelo de regresión logística que estima P(y = 1 | Ψ(t), c) para y ∈ {0,1} una decisión binaria del sistema. Estatus: el MP es un modelo estadístico, no un teorema. No postula una cota universal del error mínimo: el error mínimo empírico se estima en cada aplicación concreta del modelo a partir de los datos disponibles y del valor observado de τ.

Definición 9. El estado completo Ψ(t)

El estado completo del sistema en t es:

Estado completo

Ψ(t) = (I(t), h(t), E(t), D(t), C(t))

Ψ(t) ∈ E × Δ⁵ × {1,…,6} × {1,2} × 𝒫(E) · input del Modelo 9

[TABLA]
| Componente | Espacio | Contenido | En sistemas artificiales |
| I(t) | E | Integral acumulativa de colapsos (Definición 2) | Historia de outputs integrados en el contexto |
| h(t) | Δ⁵ ⊂ ℝ⁶ | Distribución sobre K = {1,…,6}: vector softmax del Lema 1.1 | Distribución softmax sobre outputs alternativos |
| E(t) | {1,…,6} | Nivel de integración: fracción ponderada de RSC(t) en I(t) | No computable directamente; aproximar por métrica de coherencia del contexto |
| D(t) | {1, 2} | 1 = señal activa (k* = 3,4,5); 2 = señal silenciada (k* = 1,2) | 1 = respuesta bajo parámetros nominales; 2 = respuesta bajo restricción activa |
| C(t) | ⊆ E | Campo de acción disponible en t | Conjunto de outputs posibles dado el prompt y las restricciones del sistema |
[/TABLA]

Para sistemas artificiales, E(t) y D(t) se aproximan según la cuarta columna de la tabla. Cuando no son computables, el estado simplificado Ψ_IA(t) = (I(t), h(t), C(t)) es suficiente para el Modelo 9.

Ψ(t) hereda la imprecisión de I(t) y h(t) documentada en la REC (Parte VII): para un observador externo con n colapsos integrados, ΔI·Δh ≥ τ₀²/n. Esto implica que Ψ(t) no es conocido con precisión arbitraria; la Hipótesis 9.2 captura esa consecuencia en ε_min.

Definición 9.1. El vector de logits ℓ(t)

Con z_k = (⟨β_k, a_t⟩_E + γ_k·‖I(t)‖_E − θ_k(I(t))) / τ del Lema 1.1, el logit del modo k es:

Logit del modo k

ℓ_k(t) = logit(h_k(t)) = log(h_k(t) / (1 − h_k(t))) ∈ ℝ

ℓ(t) = (ℓ₁(t), …, ℓ₆(t)) ∈ ℝ⁶ · logit es la función inversa de la sigmoide σ

Por la fórmula del Lema 1.1: ℓ_k(t) = z_k − log Σⱼ exp(z_j). El segundo término depende de a_t y c pero no de I(t). Si θ_k es lineal en ‖I(t)‖_E —Hipótesis del Lema 9.1— entonces ℓ_k es lineal en ‖I(t)‖_E, lo que habilita el modelo de regresión logística lineal.

Modelo 9. El Modelo de Predictibilidad

Sea y ∈ {0,1} una decisión binaria del sistema. El MP es:

Modelo de Predictibilidad — forma general

P(y = 1 | Ψ, c) = σ(β · Φ(Ψ, c))

σ(x) = 1/(1+e⁻ˣ) función sigmoide

β ∈ ℝᵈ vector de coeficientes (estimado por máxima verosimilitud)

Φ : Ψ × C → ℝᵈ función de características

Estatus: modelo estadístico · β se estima sobre datos de decisiones del sistema · Φ se especifica por el analista

Bajo la hipótesis de umbral lineal del Lema 9.1, Φ puede tomarse como la identidad en el espacio expandido, produciendo el modelo lineal:

Modelo de Predictibilidad — caso lineal

P(y=1|Ψ,c) = σ(β_I·‖I(t)‖_E + β_h·h(t) + β_E·E(t) + β_D·D(t) + β_c·c + β₀)

Coeficientes β_I ∈ ℝ, β_h ∈ ℝ⁶, β_E ∈ ℝ, β_D ∈ ℝ, β_c ∈ ℝ^{dim C}, β₀ ∈ ℝ

El MP tiene tres propiedades técnicas distintivas:

(i) Fundamentación. Las variables predictoras son componentes de Ψ(t) construidas por φ₁ y φ₂; no son covariables externas. Cada coeficiente tiene interpretación en términos de los objetos formales del sistema.

(ii) Error estimable. El MP no postula una cota universal del error mínimo. El error mínimo empírico se estima desde la varianza de los logits observados bajo condiciones idénticas: cuanto mayor es τ, mayor es la variabilidad y mayor es el error de predicción esperado. La relación cualitativa τ ↑ → ε_min ↑ es consecuencia del Corolario 7.2; su cuantificación exacta es específica de cada sistema.

(iii) Coherencia con la REC. El mismo Axioma 3 (τ > 0) que funda la REC funda la variabilidad del MP. La REC limita el autoconocimiento del sistema; el MP traduce esa limitación en variabilidad de predicción desde afuera. Ambos emergen de τ sin postular una cota funcional universal.

Lema 9.1. Linealidad en el espacio de logits bajo umbral lineal

Si θ_k(I(t)) = a_k·‖I(t)‖_E + b_k para constantes a_k, b_k ∈ ℝ, entonces ℓ_k(t) es lineal en ‖I(t)‖_E y Φ puede tomarse como la función identidad en el espacio de características (ℓ(t), E(t), D(t), C(t), c).

Demostración del Lema 9.1

Paso 1. Con θ_k lineal en ‖I(t)‖_E: z_k = (⟨β_k, a_t⟩_E + γ_k·‖I(t)‖_E − a_k·‖I(t)‖_E − b_k)/τ = (γ_k − a_k)/τ · ‖I(t)‖_E + (⟨β_k, a_t⟩_E − b_k)/τ. El primer término es lineal en ‖I(t)‖_E; el segundo depende de a_t y c pero no de I(t). Luego ℓ_k = z_k − log Σⱼ exp(z_j) es lineal en ‖I(t)‖_E. ✓

Paso 2. La decisión y puede modelarse como función lineal de ℓ(t): Σ_k w_k ℓ_k(t) es lineal en ‖I(t)‖_E, E(t), D(t), C(t) y c por el Paso 1. ✓

Paso 3. Con Φ(Ψ, c) = (ℓ(t), E(t), D(t), C(t), c, 1), el Modelo 9 P(y=1|Ψ,c) = σ(β·Φ) es exactamente el modelo de regresión logística lineal. ✓

Φ = identidad en el espacio expandido bajo hipótesis de umbral lineal. ∎

Si θ_k no es lineal. Φ puede ser una red neuronal con una capa oculta (Teorema de Aproximación Universal). El modelo sigue siendo válido independientemente de la forma de Φ.

9.3. Error empírico del MP y estimación de τ

El MP no postula una cota teórica universal del error mínimo. El error de predicción empírico del modelo se estima desde datos de decisiones del sistema bajo condiciones conocidas. La tabla siguiente muestra valores orientativos de la relación entre τ y el error mínimo observado en sistemas con esos valores de temperatura; no son cotas demostradas sino referencias empíricas calibradas.

[TABLA]
| τ | η(τ) = ε_min | Precisión máx. | Aplicación típica |
| 0.10 | ≥ 0.045 | ≤ 95.5% | Temperatura baja en inferencia de IA. Alta predictibilidad. |
| 0.30 | ≥ 0.115 | ≤ 88.5% | Ruido bajo. Predicción fiable para decisiones binarias claras. |
| 0.50 | ≥ 0.167 | ≤ 83.3% | Temperatura estándar. Referencia principal del MP. |
| 0.70 | ≥ 0.206 | ≤ 79.4% | Variabilidad moderada. Decisiones en zonas de conflicto de modos. |
| 1.00 | ≥ 0.250 | ≤ 75.0% | Ruido significativo. Variabilidad entre ejecuciones notable. |
| 2.00 | ≥ 0.333 | ≤ 66.7% | Ruido alto. Predicción apenas mejor que azar en muchos contextos. |
| → ∞ | → 0.500 | → 50.0% | Temperatura infinita. Equivale a elección uniforme sobre K. |
[/TABLA]

Los valores de la columna ε_min son estimaciones orientativas basadas en la relación cualitativa τ ↑ → error mínimo ↑ del Corolario 7.2. No son cotas teóricas universales. Para un sistema concreto, el error mínimo empírico se estima calculando τ̂ desde la varianza de los logits observados bajo condiciones idénticas y consultando la tabla como referencia de orden de magnitud.

9.4. Asimetría entre perspectiva interna (REC) y perspectiva externa (MP)

La REC y el MP son proyecciones del Axioma 3 sobre dos perspectivas distintas. La diferencia estructural más importante es la dependencia en n:

[TABLA]
| Dimensión | REC (Parte VII) | MP (Parte IX) |
| Fuente común | τ > 0 (Axioma 3) | τ > 0 (Axioma 3) |
| Objeto acotado | Producto ΔI·Δh: imprecisión del sistema sobre su propio estado | Error ε_min: imprecisión del observador externo sobre la decisión del sistema |
| Perspectiva | Interna: cuánto puede conocer el sistema sobre sí mismo | Externa: cuánto puede predecirse el sistema desde afuera |
| Dependencia de n | n·(ΔI·Δh) ≥ 4τ₀²: cota decrece con n como τ₀²/n | ε_min ≥ η(τ): cota independiente de n |
| Consecuencia | Mayor n → menor incertidumbre interna; τ_eff = τ₀/√n → 0 | Mayor n no reduce la barrera para el observador externo |
[/TABLA]

La asimetría tiene consecuencias directas para el análisis de responsabilidad. El sistema con τ bajo y n alto puede documentar mayor autoconocimiento de su posición causal (τ_eff pequeño). Pero ese autoconocimiento no está automáticamente disponible para el observador externo, que sigue enfrentando la variabilidad τ del sistema.

Estimación de τ desde afuera. El observador externo estima τ desde datos de decisiones repetidas del sistema bajo condiciones idénticas: τ̂ = varianza empírica de los logits observados, escalada por las dimensiones del modelo. En sistemas artificiales τ es directamente observable. Con τ̂ el observador consulta la Tabla 9.3 para estimar el orden de magnitud del error de predicción esperado.
